# Contributing and getting in touch

Thanks for exploring my work. Choose the repository that matches your suggestion:

- **This profile repository:** broken profile links, inaccessible artwork, wording corrections or inaccurate project descriptions.
- **[OrbitDrop](https://github.com/sasukefrontenddev/orbitdrop):** native desktop app bugs and feature requests.
- **[OrbitDrop website](https://github.com/sasukefrontenddev/orbitdrop-website):** download-site issues and web accessibility.
- **[Trip Deck](https://github.com/sasukefrontenddev/trip-deck)** and **[Rava Fitness](https://github.com/sasukefrontenddev/rava-fitness):** feedback about those projects.

Read the target repository's contribution and security guidance before opening an issue or PR. Search existing issues first and keep each report focused.

## A useful bug report

Describe what you expected, what happened, the steps to reproduce it, and the app/browser/operating-system version. Use a small synthetic example. Remove names, private files, contact information, access tokens and other confidential details from screenshots and logs.

Do not publish sensitive vulnerability details in a public issue. Use the affected project's security policy or private vulnerability-reporting option when available. If neither is available, ask the maintainer for a private reporting channel without disclosing the vulnerability or affected data publicly.

## Pull requests

Explain the problem and the resulting behavior, include relevant checks, and keep the diff small. Credit genuine collaborators accurately; don't add coauthors who didn't contribute. Follow the target repository's review and test requirements.

For profile-only changes, check relative links and artwork, readable text alternatives, narrow-screen rendering and the accuracy of the claims. Never reveal the identity, repository, deployment address, screenshots or data of the anonymous private project featured in the profile.

## Community participation

Helpful bug reports, thoughtful reviews, reproducible examples and useful answers are welcome. No star exchanges, artificial accounts, fabricated endorsements or badge-farming contributions. Achievements are awarded by GitHub, not by this repository.
